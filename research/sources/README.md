# Sources

The PDFs used for the rule research are not committed, because they are third-party documents. Download them from the original publishers:

| Local file name | What it is | Where to get it |
|---|---|---|
| `bkk-comprehensive-plan-2556-gazette.pdf` | Bangkok Comprehensive Plan B.E. 2556 (2013), ministerial regulation; zone ย.10 is in ข้อ 17, FAR bonuses in ข้อ 51-57 | https://download.asa.or.th/03media/04law/cpa/mr56-bma.pdf |
| `bma-building-control-ordinance-2544.pdf` | BMA Building Control Ordinance B.E. 2544 (2001) | https://infocenter.oic.go.th/FILEWEB/CABINFOCENTER9/DRAWER041/GENERAL/DATA0002/00002769.PDF |
| `jica-thai-building-control-MRs-en-2008.pdf` | English translation of the Building Control Act ministerial regulations (MR 7, 33, 41, 55 …) | https://www.iibh.org/kijun/pdf/Thai_02_MRs.pdf |
| `thammasat-2024-thai-building-height-criteria.pdf` | Thammasat University paper on Thai building-height criteria (used only to cross-check how height is measured) | Thammasat University, 2024 |

Zoning polygons (`research/data/bkk-zoning-2556.geojson`) come from a public GitHub mirror of the BMA ArcGIS service `DOL/LupDolWms`, layer 1.
Page-level citations for every rule are in `research/RULES.md`.
